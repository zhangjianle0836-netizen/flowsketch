# 流绘 FlowSketch

流绘是一款专注流程图绘制的本地桌面工具。它不包含 Markdown 编辑器；用户在画布中维护流程和阶段备注，需要交付时再导出包含 Mermaid 流程图与阶段说明的 Markdown 文档。

## 核心能力

- 开始、处理、判断、结束四类流程节点
- 点击添加或拖拽节点，通过连接点或右侧面板建立流程关系
- 阶段级备注与连线条件维护
- 支持分支汇合与回路的自动布局，可切换横向或纵向
- 流程语义检查，定位孤立节点、缺失分支、条件遗漏与无出口路径
- 在线上插入阶段、复制所选子图、重新连接端点、对齐与等距分布
- 自动与固定连接点、可拖动标签及固定路径折点
- 缩放、小地图、撤销与重做
- `.flow.json` 工程文件打开、原子保存和异常草稿恢复
- Markdown、原生 SVG 与 PNG 导出，完整包含绕行连线与标签
- PNG 1×/2×/3×倍率和透明背景，大图自动限制像素规模
- 跟随系统的亮色与暗色主题
- 键盘可操作的节点创建、属性维护和删除

## 技术架构

- Electron：桌面窗口与本地文件能力
- 安全 preload：隔离渲染层与 Node.js，只暴露白名单文件 API
- React + TypeScript：组件与交互状态
- React Flow：流程图画布
- Vite：前端构建
- Vitest：数据模型与 Markdown 导出测试
- electron-builder：桌面安装包

## 工程文件

流绘使用带版本号的 `.flow.json` 作为可编辑源文件。文件中保存节点、连线、画布位置、阶段类型和备注。Markdown 是导出文档，不再作为编辑源。打开工程时会先完成校验，再切换当前保存目标；旧工程中无效的连接点会回退到可用点位，旧版条件文字会显示为连线标注。编辑后会自动保存，关闭窗口时会写入尚未完成自动保存的最新更改。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Cmd/Ctrl + S` | 保存 |
| `Cmd/Ctrl + Shift + S` | 另存为 |
| `Cmd/Ctrl + Z` | 撤销 |
| `Cmd/Ctrl + Shift + Z` | 重做 |
| `Enter` | 为画布中已聚焦的节点新增同级阶段 |
| `Tab` | 为画布中已聚焦的节点新增下级阶段 |
| `Delete / Backspace` | 删除所选节点或连线 |
| `Shift/Cmd/Ctrl + 单击` | 将元素加入或移出当前选择 |
| `Cmd/Ctrl + D` | 复制所选阶段及其内部连线 |
| `Cmd/Ctrl + A` | 选择画布中的全部元素 |
| `Esc` | 取消当前选择 |
| `Shift + 1` | 显示全部阶段 |
| `Shift + 2` | 聚焦所选阶段 |
| `0` | 恢复为 100% 缩放 |
| `Cmd/Ctrl + Shift + E` | 导出 Markdown |

## 画布导航

- 滚动鼠标滚轮可上下移动画布，按住 `Shift` 滚动可左右移动画布。
- 触控板双指滑动可自由移动画布，双指捏合可缩放。
- 按住 `Cmd/Ctrl` 滚动，以指针位置为中心缩放画布。
- 按住 `Space` 并使用鼠标左键拖动，或直接使用鼠标中键拖动，可自由移动画布。
- 使用鼠标左键拖动画布空白区域可框选节点；按住 `Shift/Cmd/Ctrl` 单击可增减选择。
- 选择多个阶段后，拖动其中任意一个即可整体移动。
- 多选阶段会保持彼此的相对位置并统一吸附网格，相连线条会在拖动时自动重新布线。

## 建立连线

- 画布操作：可从任意点位拖动到另一个节点的任意点位；画布拖动建立的连线固定所选连接点，不会被自动优化覆盖。面板建立的连线默认自动选择点位，可在连线设置中切换。
- 连线自动采用正交避障路径；多条边共用通道时会自动分流，避免节点遮挡和路线混淆。
- 点击连线会按箭头方向显示流动高亮，便于确认起点和终点；双击连线可快速编辑标注，标注会自动避让节点和其他标签，并同步进入 Mermaid 流程图；选择连线后可拖动标注或输入位置。系统启用“减少动态效果”时自动改为静态高亮。
- 处理节点在左、右、上方和下方提供多个连接点，判断节点在菱形四个顶点提供连接点；点位仅在节点选中或正在连接时以低饱和提示显示。
- 面板操作：选中起点节点，在右侧“添加连线”中选择目标阶段并确认；该方式支持纯键盘操作。
- 选择已有连线后，可以维护条件说明或直接删除；说明会同步进入导出的 Mermaid 流程图。

## 快速编辑

- 单击节点标题可直接就地修改，按 `Enter` 确认，按 `Esc` 取消。
- 双击节点会打开备注弹窗，可集中修改标题和阶段备注。

## 流程检查与编辑

- “检查流程”会提示缺少开始/结束、开始入线、结束出线、孤立/不可达节点、缺少后续阶段、无出口路径以及判断条件遗漏或重复。点击提示定位并编辑对应节点或连线。检查不会阻止保存或导出，允许多个入口/出口和合法回路。
- 新建连接与重连禁止开始节点接收入线、结束节点发出出线。旧工程仍可打开，既有问题由检查列表提示。
- 选择连线后可插入处理阶段，原条件保留在第一段；也可拖动端点或通过属性面板修改起点、终点。
- 复制多选阶段会保留内部关系、备注、固定点位和路径，外部关系不复制。
- 固定折点按画布坐标依次经过，可拖动或用数字字段编辑。该模式优先尊重指定路径，可能穿过节点；清空折点恢复自动避障。
- 在画布节点外框上按 Tab 新增后续阶段；Shift+Tab 保持反向焦点导航。文本字段使用系统原生撤销/重做。

## 图片和 Markdown 交付

PNG 和 SVG 使用相同的标准流程形状和完整图形边界，排除连接点、选择框与编辑控件。导出采用白色背景，可选透明；不受系统主题影响。SVG 为原生路径、形状和文本，不依赖 foreignObject。PNG 可选倍率，单边限制为 8192 像素、总像素约 1600 万；超大流程会自动降低倍率并提示，SVG 保留完整矢量精度。

Mermaid 保留流程方向、节点类型、关系和分支条件，使用源节点 ID 的稳定编码减少版本差异；会重新排版，精确交付画布布局请使用 PNG/SVG。工程仍使用 v1 格式，新属性可选，兼容旧工程。
